# History

These documents are the record of how Niki Agent was built. They are kept
because they are auditable evidence, not because they describe the current
product.

| File | What it is |
| --- | --- |
| `UPSTREAM_README.md` | The upstream project's README as it stood at the fork point, preserved verbatim. |
| `UPSTREAM_DIFF.md` | Every edit made to upstream-owned files while Niki evolved out of the monorepo. |
| `DESIGN.md` | The fork-era design audit: storage, rendering, extension points, and the network policy, measured at `f57c6f38`. |
| `BASELINE.md` | Performance baselines measured before any UI change, at the same commit. |

Paths, version numbers, and names inside them describe that earlier tree. Do not
treat them as installation or contribution instructions; the current product
documentation is one directory up, starting with [`../ARCHITECTURE.md`](../ARCHITECTURE.md)
and [`../INDEPENDENCE.md`](../INDEPENDENCE.md).
